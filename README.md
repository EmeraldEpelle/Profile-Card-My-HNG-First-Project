# Frontend Wizards Stage 0 - Profile Card

A responsive, accessible profile card built with HTML, CSS, and JavaScript for the Frontend Wizards Stage 0 task.

## ✨ Features
- Semantic HTML5 structure
- Displays current time in milliseconds
- Accessible, responsive, and keyboard-navigable
- Uses `data-testid` attributes for automated testing

## 🧠 Technologies
HTML • CSS • JavaScript
